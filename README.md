# Profile Card Maker

A small browser-based tool for creating Netflix-style profile cards.

## Live app

https://mankolik.github.io/Profile-Card-Maker/

## Features

- Upload a profile picture
- Add a custom name
- Choose between multiple visual styles
- Change the accent color and text style
- Adjust image zoom and vertical position
- Export the finished card as a 1080 × 1080 PNG
- iPhone/iPad sharing support through the native share sheet

## Privacy

Everything runs locally in your browser. Uploaded images are not sent to a server.

## Usage

Open the live app, choose an image, enter a name, customize the card, then use **Save / Share PNG** to export it.

## Tech

The app is a single static `index.html` file using plain HTML, CSS, JavaScript, and the Canvas API. No build step or dependencies are required.
